# BuffTracker

Tracks how many unique players you've buffed, for any class. Every buff you cast on another player is counted under its own name (group versions like Arcane Brilliance or Greater Blessings are folded into the single-target buff), and you get milestone alerts as your unique-player count grows.

## Commands

| Command | What it does |
| --- | --- |
| `/buffs` | Show your stats |
| `/buffs chat` | Post a brag to instance/raid/party/say |
| `/buffs ignore <buff>` | Hide or unhide a buff (no name lists ignored buffs) |
| `/buffs announce` | Toggle milestone announcements to group chat |
| `/buffs errors` | Show errors the addon caught (e.g. during dungeons) |
| `/buffs reset` | Wipe all data |
